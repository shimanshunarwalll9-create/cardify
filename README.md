# Cardify – Digital Business Card Generator

## Run locally
1. Extract this ZIP.
2. Open the `cardify` folder in VS Code.
3. Open `index.html` with the Live Server extension.

## Demo admin
Email: `admin@cardify.demo`

## Included
Registration/login demo, browser localStorage, create/edit/delete cards, live preview, dashboard search/filter, admin review and user activation controls.

## Project structure
- `index.html`, `login.html`, `register.html`
- `dashboard.html`, `create-card.html`, `admin.html`
- `css/style.css`
- `js/data.js`, `js/app.js`

## Security note
This is a front-end educational prototype. Passwords and records are stored in browser localStorage, which is not secure. Do not use real passwords or sensitive personal information. A production application needs a backend, database, password hashing and server-side access control.
